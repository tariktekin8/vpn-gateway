# Code of conduct

This project is for everyone who wants to use or improve VPN Gateway. Everyone who takes part, in issues, pull
requests, reviews and discussions, follows these rules.

## Expected

- Be respectful and patient, also when you disagree.
- Assume good intent, and ask before you judge.
- Give feedback about the work, not about the person.
- Help newcomers; many users have never used a terminal.

## Not accepted

- Insults, harassment, threats, or sexual language and images.
- Attacks on someone's identity, origin, gender, religion, age, disability or any other personal trait.
- Publishing someone's private information, including an organization's hosts, addresses or credentials.
- Asking for help to break into networks or to get around an organization's security controls.

## What happens

The maintainer may edit or remove comments, close issues and pull requests, and block people who break these
rules. Report a problem to the maintainer through a private
[security report](https://github.com/tariktekin8/vpn-gateway/security/advisories/new) if it must stay private, or
by opening an issue otherwise.
